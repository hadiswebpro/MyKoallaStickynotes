# 🐨 Koala Notes

A cute and simple **Sticky Notes PWA** designed to help you organize ideas, tasks, and reminders in one place.

## ✨ Features

* 📝 Create, edit, and delete notes
* 📌 Pin important notes
* 🔍 Search through notes
* 🎨 Choose different note colors
* 🏷️ Add stickers to notes
* 🖼️ Add images to notes
* ⏰ Set reminders for notes
* ✅ Mark notes as completed
* 🖱️ Drag & drop notes
* 🌙 Dark mode
* 🐨 Animated Koala interface
* 💾 Notes are saved using Local Storage
* 📱 Progressive Web App (PWA)
* 🔔 Browser notifications
* 📦 Service Worker for PWA support

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Web APIs
* Local Storage
* Service Worker
* PWA

## 📱 PWA

Koala Notes can be installed as a Progressive Web App on supported devices.

The project includes:

* `manifest.json`
* `sw.js`
* PWA icons
* Service Worker caching

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/hadiswebpro/Koala-Notes.git
```

Open the project with VS Code and run it using **Live Server**.

Because Koala Notes uses a Service Worker, running it through a local server such as Live Server is recommended instead of opening `index.html` directly.
